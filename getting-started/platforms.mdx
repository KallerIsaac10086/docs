# 多平台访问指南

Llama Python WebUI 支持多平台访问，您可以在任何设备上随时随地使用我们的服务。

## Web 端访问

### 访问方式

1. 打开浏览器（推荐使用 Chrome、Safari、Edge 或 Firefox）
2. 在地址栏输入我们的网址
3. 登录您的账户即可开始使用

### 浏览器要求

- **推荐浏览器**：
  - Google Chrome（最新版本）
  - Safari 15+
  - Microsoft Edge（最新版本）
  - Firefox（最新版本）

- **最低要求**：
  - 支持 JavaScript 的现代浏览器
  - 屏幕分辨率不低于 1024×768

### 添加到主屏幕

**Chrome/Edge:**
1. 点击右上角菜单（⋮）
2. 选择"保存并分享" → "创建快捷方式"
3. 勾选"在窗口中打开"
4. 点击"创建"

**Safari:**
1. 点击分享按钮
2. 选择"添加到主屏幕"
3. 输入名称后点击"添加"

## iOS App

### 下载方式

1. 打开 App Store
2. 搜索 "Llama Python WebUI"
3. 点击"获取"按钮下载安装

> **系统要求**：iOS 15.0 或更高版本

### 首次使用

1. 打开 App
2. 使用您的账户登录
   - 支持邮箱密码登录
   - 支持 Apple 快捷登录
3. 登录成功后，界面与 Web 端保持一致

### 特色功能

- **Face ID/Touch ID 登录**：快速安全访问
- **离线模式**：查看已缓存的对话记录
- **推送通知**：及时获取重要提醒
- **Siri 快捷指令**：语音快速启动

### 常见问题

**Q: App 支持后台运行吗？**

A: 支持。切换到其他 App 后，生成中的回复会继续完成。

**Q: 如何在 iOS 上分享对话？**

A: 点击分享按钮，可以选择复制、发送给朋友或保存为图片。

## Android App

### 下载方式

**方式一：Google Play**
1. 打开 Google Play Store
2. 搜索 "Llama Python WebUI"
3. 点击"安装"按钮

**方式二：官网下载**
1. 访问官网下载页面
2. 下载最新 APK 安装包
3. 允许安装未知来源应用
4. 打开 APK 完成安装

> **系统要求**：Android 8.0 或更高版本

### 首次使用

1. 打开 App
2. 使用您的账户登录
   - 支持邮箱密码登录
   - 支持 Google 快捷登录
3. 登录成功后即可使用

### 特色功能

- **指纹/面部识别**：快速安全登录
- **小部件**：主屏幕快速启动
- **分屏模式**：多任务同时处理
- **深色模式**：自动跟随系统

### 常见问题

**Q: APK 安装失败怎么办？**

A: 请确保在设置中允许"安装未知来源应用"权限。

**Q: 如何关闭自动更新？**

A: 在 App 设置中关闭"自动检查更新"选项。

## 多端同步说明

### 同步内容

以下数据将在所有设备间实时同步：

- ✅ 对话历史记录
- ✅ 收藏的消息
- ✅ 个人设置偏好
- ✅ 订阅状态

### 同步机制

- **实时同步**：登录状态下，操作即时同步到云端
- **离线缓存**：无网络时的操作会在联网后自动同步
- **冲突处理**：以最新操作为准

### 使用建议

1. **保持登录**：在所有设备上使用同一账户登录
2. **定期同步**：确保设备联网以完成数据同步
3. **退出前保存**：重要操作完成后等待同步完成

### 常见问题

**Q: 为什么我的对话没有同步？**

A: 请检查：
- 是否已登录账户
- 网络连接是否正常
- 是否使用了同一账户

**Q: 如何确保数据安全？**

A: 所有同步数据均采用端到端加密，只有您的设备可以解密查看。

**Q: 可以同时在多个设备上使用吗？**

A: 可以。支持最多 5 台设备同时在线使用。
