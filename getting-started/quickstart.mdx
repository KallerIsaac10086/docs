# 快速入门指南

欢迎使用 Llama Python WebUI！本指南将帮助您快速上手使用本平台。

## 注册账户

1. 访问网站首页，点击页面右上角的 **注册** 按钮
2. 填写以下信息：
   - 邮箱地址（将作为登录账号）
   - 设置密码（建议使用强密码）
   - 确认密码
3. 点击 **立即注册** 按钮
4. 检查您的邮箱，点击验证链接完成账户激活

> **提示**：请确保使用有效的邮箱地址，账户激活后才能正常使用服务。

## 登录账户

1. 点击页面右上角的 **登录** 按钮
2. 输入您的注册邮箱和密码
3. 点击 **登录** 按钮
4. 登录成功后，将自动跳转到主界面

> **提示**：勾选"记住我"可以在 7 天内免登录访问。

## 首次使用步骤

### 1. 完善个人信息

登录后，建议先完善您的个人信息：
- 点击头像进入 **个人中心**
- 填写昵称、头像等基本信息
- 保存设置

### 2. 了解界面布局

主界面分为以下几个区域：
- **顶部导航栏**：访问各功能模块
- **左侧边栏**：显示历史记录和快捷操作
- **主内容区**：核心操作区域
- **右侧面板**：显示设置和辅助信息

### 3. 开始第一次对话

1. 在聊天界面，选择您需要的 AI 模型
2. 在输入框中输入您的问题或指令
3. 按回车键或点击发送按钮
4. 等待 AI 生成回复

## 基本操作说明

### 对话管理

- **新建对话**：点击左上角 **+** 按钮创建新对话
- **切换对话**：在左侧历史列表中点击任意对话
- **重命名对话**：鼠标悬停在对话上，点击编辑图标
- **删除对话**：鼠标悬停在对话上，点击删除图标

### 消息操作

- **复制回复**：点击消息下方的复制图标
- **重新生成**：对回复不满意？点击重新生成按钮
- **点赞/点踩**：帮助改进服务质量
- **分享对话**：生成分享链接与他人共享

### 设置选项

- **模型选择**：根据不同场景选择合适的模型
- **主题切换**：支持亮色/暗色模式
- **语言设置**：选择您偏好的界面语言
- **隐私设置**：管理数据保存和分享选项

## 常见问题

**Q: 忘记密码怎么办？**

A: 在登录页面点击"忘记密码"，输入注册邮箱，系统将发送重置链接。

**Q: 如何退出登录？**

A: 点击头像，在下拉菜单中选择"退出登录"。

**Q: 对话记录会保存多久？**

A: 默认情况下，您的对话记录将永久保存，除非您手动删除。
