## 开始新对话

### 方法一：使用快捷按钮

在左侧边栏顶部，点击 **"新对话"** 按钮（或按快捷键 `⇧⌘O`），即可立即创建一个新的对话。

### 方法二：通过 URL 参数

在浏览器地址栏访问主页时添加 `?new_chat=true` 参数，系统会自动为您创建新对话。

### 方法三：自动创建

当您选择一个历史对话并发送消息后，系统会自动保存对话记录。下次点击"新对话"时，会创建全新的对话线程。

## 查看历史对话

### 侧边栏对话列表

左侧边栏会显示您所有的历史对话，按**最后修改时间**倒序排列（最新的对话显示在最上方）。

每个对话卡片显示：
- **对话名称**：默认显示对话的第一条消息内容，或自动生成的标题
- **最后活跃时间**：显示对话的最后更新时间
- **操作菜单**：点击对话卡片右侧的 `⋯` 按钮，可以：
  - 📝 **重命名**：自定义对话名称
  - ⬇️ **导出**：下载对话记录为 JSON 文件
  - 🗑️ **删除**：删除该对话（删除后不可恢复）

### 切换对话

点击任意历史对话卡片，即可切换到该对话，继续之前的交流。系统会自动加载该对话的完整消息记录。

### 云端同步

如果您已登录账户并启用了云服务，您的对话记录会自动同步到云端。在其他设备登录同一账户后，可以查看和继续这些对话。

## 对话界面介绍

### 消息区域

对话界面的主体部分显示消息记录：

- **用户消息**：显示在右侧，背景为强调色
- **AI 回复**：显示在左侧，包含完整的 Markdown 渲染内容
- **时间戳**：每条消息都标注了发送时间
- **状态指示**：AI 正在回复时会显示加载动画

### 输入区域

底部的输入框支持：

- **多行输入**：自动调整高度，支持输入长文本
- **快捷操作**：
  - `Enter`：发送消息
  - `Shift + Enter`：换行
  - `↑`：快速编辑最后一条用户消息

### 模型选择器

输入框上方显示当前选择的模型，点击可打开模型选择菜单，查看和切换不同模型。

### 工具调用开关

点击工具图标可以启用/禁用工具调用功能。启用后，AI 可以在回复时调用外部工具（如案例检索、法条查询等）。

## 使用技巧

### 1. 为对话命名

建议为新对话起一个描述性的名称，方便日后查找。例如：
- "劳动争议 - 加班费咨询"
- "房屋租赁合同纠纷"
- "离婚协议起草"

### 2. 合理使用工具调用

在处理具体法律问题时，启用工具调用可以让 AI 检索相关案例和法条，提供更准确的回答。但注意：
- 工具调用会产生额外的 API 处理时间
- 启用工具调用时，高级安全防护会自动禁用

### 3. 导出重要对话

对于重要的咨询记录或生成的法律文书，建议使用导出功能保存为 JSON 文件，便于归档和备份。

### 4. 使用快捷键

- `⇧⌘O`：快速创建新对话
- `Enter`：发送消息
- `↑`：编辑最后一条消息

### 5. 消息重新生成

如果对 AI 的回复不满意，可以点击消息下方的"重新生成"按钮，让 AI 重新回答同一个问题。

### 6. 对话清理

定期删除不再需要的历史对话，保持对话列表整洁，也便于快速找到重要对话。

> **提示**：对话记录存储在本地数据库中，即使关闭浏览器也不会丢失。启用云服务后，可以实现跨设备同步。
