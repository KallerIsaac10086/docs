## 什么是工具调用

工具调用（Function Calling）是 LawChat 的一项高级功能，允许 AI 模型在回答问题时主动调用外部工具，如：

- 🔍 **案例检索**：搜索相关法律案例
- 📚 **法条查询**：查找适用的法律法规
- 📊 **数据分析**：处理和分析法律数据
- 🔎 **信息检索**：获取实时信息

通过工具调用，AI 不再仅依赖训练数据，而是能够获取最新、最准确的法律信息，提供更专业的回答。

## 如何启用工具调用

### 步骤一：打开工具菜单

在对话界面的输入框上方，找到并点击 **工具图标**（🔧），会弹出工具设置菜单。

### 步骤二：启用工具调用

在菜单中，点击 **"启用工具调用"** 开关，将其切换到开启状态。

### 步骤三：查看可用工具

启用后，您可以在"可用工具"子菜单中查看当前系统提供的所有工具，包括：

- 工具名称
- 工具描述
- 工具状态（启用/禁用）

### 步骤四：开始使用

启用工具调用后，AI 会在处理您的问题时自动判断是否需要调用工具，并在需要时执行相应的工具调用。

## 可用工具介绍

### 1. 案例检索工具

**功能**：搜索与您的问题相关的法律案例

**适用场景**：
- 需要了解类似案件的判决结果
- 想查看法院对某类问题的态度
- 需要类案参考来评估案件走向

**使用示例**：
```
用户：我想了解最近法院对"996 工作制"违法认定的案例

AI：（自动调用案例检索工具）
正在检索相关案例...
找到 15 个相关案例，其中：
- 北京市海淀区人民法院 (2024) 京 0108 民初 XX 号
- 上海市浦东新区人民法院 (2024) 沪 0115 民初 XX 号
...
```

### 2. 法条查询工具

**功能**：查询具体的法律法规条文

**适用场景**：
- 需要查找特定问题的法律依据
- 想确认某个法条的具体内容
- 需要了解某部法律的完整规定

**使用示例**：
```
用户：劳动合同法关于经济补偿的规定是什么？

AI：（自动调用法条查询工具）
正在查询相关法条...
《中华人民共和国劳动合同法》：
- 第四十六条：有下列情形之一的，用人单位应当向劳动者支付经济补偿...
- 第四十七条：经济补偿按劳动者在本单位工作的年限...
```

### 3. 法律词典工具

**功能**：解释法律专业术语的含义

**适用场景**：
- 不理解某个法律术语
- 需要准确的法律概念定义
- 想深入了解法律术语的适用条件

**使用示例**：
```
用户：什么是"表见代理"？

AI：（自动调用法律词典工具）
表见代理是指...
构成要件：
1. 行为人无代理权
2. 相对人有理由相信行为人有代理权
3. 相对人主观上为善意
法律后果：...
```

### 4. 文书模板工具

**功能**：提供标准法律文书模板

**适用场景**：
- 需要起草起诉状
- 想准备答辩状
- 需要合同模板参考

**使用示例**：
```
用户：我需要一份离婚起诉状的模板

AI：（自动调用文书模板工具）
正在获取起诉状模板...

原告：[姓名]，[性别]，[民族]，[出生日期]...

1. 判令原被告离婚...

...
```

## 工具调用的工作原理

### 1. 问题理解

当您发送问题后，AI 会首先理解您的问题意图，判断是否需要调用外部工具。

### 2. 工具选择

如果确定需要工具辅助，AI 会从可用工具列表中选择最合适的工具。

### 3. 参数生成

AI 会根据您的问题生成工具调用所需的参数，例如：
- 检索关键词
- 查询条件
- 过滤参数

### 4. 执行调用

系统执行工具调用，获取工具返回的结果。

### 5. 结果整合

AI 将工具返回的结果与自身知识整合，生成最终的回答。

## 使用场景

### 场景一：法律咨询

**问题**："我被公司违法解除了，能赔多少钱？"

**工具调用流程**：
1. AI 调用**法条查询工具**，获取《劳动合同法》关于违法解除的规定
2. AI 调用**案例检索工具**，查找类似案件的赔偿标准
3. 综合法条和案例，给出详细的赔偿计算建议

**回答质量**：相比不使用工具，回答更准确、更有依据

### 场景二：案件分析

**问题**："这个劳动争议案件我胜算大吗？"

**工具调用流程**：
1. AI 调用**案例检索工具**，检索类似案件的判决结果
2. 分析类案的胜诉率和判决倾向
3. 结合您的具体情况，给出胜算评估

**回答质量**：基于真实案例数据，评估更客观

### 场景三：文书起草

**问题**："帮我写一份劳动仲裁申请书"

**工具调用流程**：
1. AI 调用**文书模板工具**，获取标准的仲裁申请书格式
2. 根据您的具体情况填充内容
3. 调用**法条查询工具**，确保引用的法律依据准确

**回答质量**：格式规范、法条准确、可直接使用

### 场景四：合同审查

**问题**："帮我审查这份劳动合同有没有问题"

**工具调用流程**：
1. AI 调用**法条查询工具**，获取劳动法的强制性规定
2. 逐条比对合同条款与法律规定
3. 标记出可能违法或存在风险的条款

**回答质量**：审查更全面、风险提示更准确

## 注意事项

### 1. 响应时间

使用工具调用会增加处理时间：
- 简单问题（不调用工具）：1-3 秒
- 复杂问题（调用 1-2 个工具）：5-10 秒
- 深度分析（调用多个工具）：10-30 秒

### 2. 高级安全防护

**重要**：启用工具调用时，**高级安全防护会自动禁用**。

原因：
- 工具调用需要模型自由判断何时调用工具
- 高级安全防护会限制模型的某些输出
- 两者同时启用可能影响工具调用效果

### 3. 使用限制

- 部分工具可能需要特定的会员等级
- 工具调用有每日次数限制（根据会员等级）
- 某些复杂工具调用可能消耗额外积分

### 4. 结果准确性

虽然工具调用能提供更准确的信息，但仍需注意：
- 案例检索结果可能与您的情况不完全相同
- 法条可能存在更新，请以官方发布为准
- AI 的解读仅供参考，重要事项请咨询专业律师

## 最佳实践

### 1. 明确表达需求

**不好的提问**：
```
"我该怎么办？"
```

**好的提问**：
```
"公司拖欠我 3 个月工资，我想知道：
1. 相关法律规定是什么？
2. 类似案例一般怎么判？
3. 我应该准备哪些证据？"
```

### 2. 提供必要信息

让 AI 能够更好地调用工具：
- 案件类型（劳动、合同、婚姻等）
- 关键事实（时间、地点、金额等）
- 您的诉求（赔偿、履行、解除等）

### 3. 合理期待

工具调用是辅助功能，不是万能钥匙：
- 简单问题可能不需要调用工具
- 复杂问题可能需要多次工具调用
- 最终判断仍需结合具体情况

### 4. 验证结果

对于重要信息，建议：
- 核对引用的法条原文
- 查看案例的完整判决书
- 咨询专业律师获取第二意见

## 常见问题

### Q: 为什么有时候 AI 不调用工具？

A: AI 会根据问题自动判断是否需要工具。以下情况可能不调用工具：
- 问题简单，AI 自身知识足够回答
- 问题不涉及具体法条或案例
- 工具调用功能未启用

### Q: 可以手动指定使用哪个工具吗？

A: 目前 AI 会自动选择最合适的工具。您可以在问题中明确表达需求，引导 AI 使用特定工具，例如：
- "请帮我查一下相关案例"
- "这个在法律上是怎么规定的？"

### Q: 工具调用的结果准确吗？

A: 工具本身返回的数据是准确的，但 AI 的解读可能存在偏差。建议：
- 重要法条请核对原文
- 关键案例请查看完整判决
- 重大决策请咨询专业律师

### Q: 工具调用会额外收费吗？

A: 基础工具调用包含在会员权益内，但：
- 部分高级工具可能需要额外积分
- 频繁调用可能触及每日限制
- 具体收费标准请查看会员说明

> **提示**：工具调用是 LawChat 的核心竞争力之一。合理使用工具调用，可以让 AI 的回答更专业、更准确、更有依据。建议在处理重要法律问题时务必启用此功能。
